#### Поддерживаемые команды

* **add** – добавление нового пользователя. Для пользователя задаётся имя, по которому его можно идентифицировать.
* **list** – вывод списка всех пользователей.
* **send** – отправка сообщения от одного пользователя другому. Для сообщения указывается заголовок и текст.

  * Сообщение добавляется в список *отправленных* у отправителя.
  * Если сообщение не считается спамом с точки зрения получателя, оно добавляется в его список *входящих*.
  * В противном случае оно попадает в список *спама*.
* **inbox** – отображение входящих сообщений для конкретного пользователя, не помеченных как спам.
* **spam** – отображение входящих сообщений для конкретного пользователя, помеченных как спам.
* **outbox** – отображение исходящих сообщений для конкретного пользователя.
* **setfilter** – установка спам-фильтра для конкретного пользователя.

---

### Спам-фильтры

У одного пользователя может быть несколько подфильтров. Если хотя бы один из них считает сообщение спамом, то оно помечается как спам.

Поддерживаются следующие типы фильтров:

1. **simple** – сообщение считается спамом, если в заголовке или тексте встречается слово *spam* (в любом регистре).
2. **keywords** – сообщение считается спамом, если заголовок или текст содержит одно из заданных ключевых слов (в любом регистре).

   * Список ключевых слов вводится через пробел.
3. **repetition** – сообщение считается спамом, если какое-либо слово в тексте (но не в заголовке) встречается чаще, чем заданное количество раз.

   * Например:

     * при `repetition 3` текст *Hello goodbye hello goodbye hello* **не является** спамом;
     * при `repetition 2` (и меньших значениях) этот же текст **считается** спамом.
   * Максимальное число повторений вводится с клавиатуры как целое положительное число.
4. **sender** – все сообщения конкретного отправителя считаются спамом.

   * Имя отправителя вводится с клавиатуры.

---

### Работа с фильтрами

При вводе команды **setfilter** программа переходит в режим чтения списка спам-фильтров.

* Фильтры указываются один за другим.
* Для завершения ввода фильтров используется строка **done**.
* Получившийся набор фильтров назначается выбранному пользователю.

По умолчанию у пользователя нет ни одного спам-фильтра.
